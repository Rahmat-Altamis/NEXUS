# Kebijakan Keamanan: Reset Password Akun (SYNTHETIC)

Nusantara Digital Group — dokumen fiktif untuk pengujian. Seluruh isi sintetis.

Prosedur reset password akun kantor dilakukan mandiri melalui laman bantuan TI.
Untuk reset password, karyawan membuka laman bantuan, memilih menu reset
password akun, lalu mengikuti tautan verifikasi yang dikirim ke surel kantor.

Kata sandi baru untuk akun kantor minimal terdiri atas dua belas karakter
dengan kombinasi huruf dan angka. Jangan pernah membagikan password akun
kepada siapa pun, termasuk kepada tim TI.
